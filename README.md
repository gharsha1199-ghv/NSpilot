# Video Editor Portfolio

Open `index.html` in a browser to preview.

## What to edit
- `script.js` (top of file): the `REELS` list. Change each reel's title, tag, time and Instagram `url`.
- `index.html`: name (search "Alex Rivera"), hero text, about text, services, email (`mailText`) and the Instagram link (`igLink`).
- `style.css`: colors and fonts are the variables at the top (`:root`). Change `--accent` to recolor the site.
